# Presets

Example plugins for common search verticals. Load one with `Analyzer(plugins=["preset:local"])`
and stack your own plugin directory after it. They are starting points, not tuned models.

- `web` — web / content search (titles, lyrics, recipes, reviews)
- `commerce` — product search (accessories, shipping conditions)
- `local` — place / business search (branch markers, proximity, opening hours, place names)
